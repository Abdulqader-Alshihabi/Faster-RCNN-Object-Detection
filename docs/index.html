Faster R-CNN Two-Stage Pipeline Architecture

1 ResNet-50 Backbone

Extracts rich multi-scale convolutional feature maps via Feature Pyramid Networks (FPN).

→
2 Region Proposal Network (RPN)

Slides over feature maps to generate candidate object bounding boxes (RoIs) with objectness scores.

→
3 RoIAlign Pooling

Samples exact feature patches without spatial quantization, preserving pixel alignment.

→
4 Fast R-CNN Head

Executes multi-class softmax classification and final bounding box delta regression.
